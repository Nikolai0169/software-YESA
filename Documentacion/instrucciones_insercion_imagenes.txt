Documentación: Inserción de imágenes y modelos 3D en YESA

Categorías:
1) Postman
2) Backend
3) Frontend

1) POSTMAN

A) Insertar una única imagen para un producto
   - URL: POST http://localhost:5000/api/admin/productos
   - Tipo: multipart/form-data
   - Campos:
     * nombre
     * descripcion
     * precio
     * stock
     * categoriaId
     * subcategoriaId
     * imagen (archivo JPG/PNG/GIF)
   - Ejemplo de cuerpo (form-data):
     imagen: archivo
     nombre: "Alcancía personalizada"
     descripcion: "Producto con imagen única"
     precio: 42000
     stock: 10
     categoriaId: 1
     subcategoriaId: 2
   - Resultado: el producto guarda `imagen` y se muestra como imagen principal.

B) Insertar varias imágenes para un producto
   - URL: POST http://localhost:5000/api/admin/productos
   - Tipo: multipart/form-data
   - Campos:
     * nombre
     * descripcion
     * precio
     * stock
     * categoriaId
     * subcategoriaId
     * imagenes (varios archivos JPG/PNG/GIF)
   - Ejemplo de cuerpo (form-data):
     imagenes: archivo1.jpg
     imagenes: archivo2.png
     imagenes: archivo3.gif
     nombre: "Alcancía multipantalla"
     descripcion: "Producto con varias imágenes"
     precio: 52000
     stock: 5
     categoriaId: 1
     subcategoriaId: 2
   - Resultado: el producto guarda un arreglo en `imagenes` y la primera imagen también se asigna a `imagen`.

C) Añadir modelos 3D por producto
   - URL: PUT http://localhost:5000/api/admin/productos/:id
   - Tipo: application/json
   - Body JSON ejemplo:
     {
       "nombre": "Producto con modelo 3D",
       "precio": 58000,
       "stock": 4,
       "categoriaId": 1,
       "subcategoriaId": 2,
       "modelos3D": [
         { "nombre": "Modelo clásico", "url": "https://example.com/modelo1.glb" },
         { "nombre": "Modelo premium", "url": "https://example.com/modelo2.glb" }
       ]
     }
   - Nota: si el backend todavía no asigna `modelos3D` desde `req.body`, hay que actualizar el controlador.

2) BACKEND

A) Cómo funciona una sola imagen
   - El modelo `backend/models/Producto.js` define el campo `imagen`.
   - El middleware `uploadIfMultipart` en `backend/routes/admin.routes.js` permite subir archivos.
   - El controlador `backend/controllers/producto.controller.js` toma el archivo enviado en el campo `imagen` y guarda su nombre en `producto.imagen`.
   - El archivo físico se almacena en `backend/uploads/`.

B) Cómo funciona varias imágenes
   - El modelo `Producto` también define `imagenes` como `DataTypes.JSON`.
   - El controlador lee `req.files.imagenes` y extrae los nombres de archivo:
       `imagenes = req.files.imagenes.map(file => file.filename)`
   - Guarda el arreglo en `producto.imagenes`.
   - Para compatibilidad con vistas anteriores, asigna `producto.imagen = imagenes[0]`.
   - En actualización de producto, si llegan nuevas imágenes, elimina las anteriores y guarda las nuevas.

C) Cómo añadir modelos 3D
   - El campo `modelos3D` está definido en `backend/models/Producto.js` como JSON.
   - Esta propiedad puede guardar cualquier estructura JSON correspondiente a los modelos 3D.
   - Ejemplo válido:
       {
         "modelos3D": [
           { "nombre": "Modelo clásico", "url": "https://example.com/modelo1.glb" },
           { "nombre": "Modelo premium", "url": "https://example.com/modelo2.glb" }
         ]
       }
   - Si el controlador no procesa `modelos3D`, debe agregarse en `producto.controller.js` dentro de `crearProducto` y `actualizarProducto`:
       if (req.body.modelos3D) producto.modelos3D = req.body.modelos3D;
   - No se trata de un archivo subido por Multer; se envía por JSON.

3) FRONTEND

A) Mostrar una única imagen
   - El frontend utiliza `producto.imagen` en la tarjeta y el detalle de producto.
   - Si el producto sólo tiene `imagen`, se muestra como imagen principal.
   - El helper `frontend/src/utils/helpers.js` construye la URL completa: `http://localhost:5000/${imagePath}`.

B) Mostrar varias imágenes
   - En `frontend/src/pages/ProductDetailPage.js` se detecta si `producto.imagenes` existe.
   - Si hay varias imágenes, se construye una mini galería de miniaturas.
   - Al seleccionar una miniatura, cambia la imagen principal en la vista.
   - Si no hay `producto.imagenes`, el frontend usa `producto.imagen` como respaldo.

C) Usar los modelos 3D desde el frontend
   - El botón `Personalizar 3D` aparece en `ProductCard.js` y `ProductDetailPage.js`.
   - Al hacer clic, abre el modal `frontend/src/components/Personalization3DModal.js`.
   - El modal permite elegir:
       * modelo 3D
       * color
       * acabado
   - Actualmente la selección se maneja localmente en el frontend.
   - Si `producto.modelos3D` existe, la página de detalle muestra información de los modelos disponibles.

Notas finales:
- Para subir imágenes en Postman usa multipart/form-data.
- Para enviar `modelos3D`, usa JSON en la ruta de actualización.
- El backend debe soportar tanto `imagen` como `imagenes` en admin.routes.js con `uploadIfMultipart`.
- El frontend solo muestra la personalización; aún no se guarda automáticamente en la orden.
